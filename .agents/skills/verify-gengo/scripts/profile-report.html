Scope and interpretation

This small indexed customer dataset measures this customer-lookup workload from the machine running Gengo. It does not establish production database capacity. Results include network effects and other project activity.

The profiles use different durations, warm-ups, repetitions, and maximum load. Cross-profile differences are descriptive and do not establish a regression or statistical significance. A median p95 is a median of per-repetition percentiles, not a pooled percentile.

A highest passing tested client count is a lower bound within this sweep; saturation may be above it. Supabase telemetry is project-wide and is not a per-step server measurement.
